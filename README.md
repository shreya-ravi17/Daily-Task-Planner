# Daily Task Planner

A simple daily task planner built using HTML, CSS, Bootstrap 5, and JavaScript.

## Live Demo

https://daily-task-planner-project.netlify.app/

## Features

* Add tasks
* Edit tasks
* Mark tasks as completed
* Delete tasks
* Filter tasks by All, Pending, and Completed
* Save tasks using LocalStorage
* Responsive design

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* LocalStorage
